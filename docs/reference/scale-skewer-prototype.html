음계 꼬치구이

아래 건반 위의 재료를 눌러 꼬치에 차례로 꽂아요. 누를 때마다 소리가 나고 악보에 음표가 그려져요. 다장조(C)와 바장조(F) 음계 꼬치를 만들어 봅니다.

소리가 들리지 않으면 휴대폰 볼륨과 무음 설정을 확인하세요. 소리 없이도 끝까지 할 수 있어요.
